## Маршрутизация по темам (КРИТИЧНО)

Правила проекта разложены по тематическим файлам в `docs/rules/`. Перед тем как ответить или написать код, **определи тему задачи** и **прочитай только соответствующие файлы**.

| Если задача про… | Прочитай файлы |
| --- | --- |
| Спрайты, пиксель-арт, Aseprite, импорт 2D | [2d-art.md](docs/rules/2d-art.md) |
| 3D-модели, шейдеры, освещение | [3d-art.md](docs/rules/3d-art.md) |
| HUD, меню, интерфейс | [ui-ux.md](docs/rules/ui-ux.md) |
| Музыку, звуки, аудио-шины | [audio.md](docs/rules/audio.md) |
| Структуру кода, C#, asmdef, архитектуру | [architecture.md](docs/rules/architecture.md) |
| Тесты, EditMode, PlayMode, ручные проверки | [testing.md](docs/rules/testing.md) |
| Процесс работы, ревью, майлстоуны, правила | [workflow.md](docs/rules/workflow.md) |

**Запрещено** применять правила из `3d-art.md` к 2D-проекту и правила из `2d-art.md` к 3D-проекту. Если задача затрагивает несколько тем, прочитай все соответствующие файлы.

## Автоматическое извлечение правил

Если в процессе диалога пользователь сформулировал новую конвенцию или дал исправление с причиной:

1. Определи тему правила.
2. Проверь правило через [agents-md-guard](.agents/skills/agents-md-guard/SKILL.md).
3. Покажи пользователю точную формулировку и путь. Спроси «Записать это правило в `docs/rules/[тема].md`?»
4. После подтверждения запиши правило только в соответствующий тематический файл.
