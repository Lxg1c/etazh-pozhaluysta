# Интерфейс и UX

- Показывай один основной индикатор для одной величины. Два таймера одной смены усложняют чтение оставшегося времени.
- Выравнивай кнопку, метку или счётчик с объектом, к которому они относятся. Пространственная связь помогает быстрее сопоставить управление и состояние игры.
- Показывай данные, необходимые для выбора, до действия игрока. Награду, ограничения и последствия нужно понимать в момент принятия решения.
- Давай визуальный отклик на важное игровое событие. Игроку должно быть понятно, что произошло и какое состояние изменилось.
- Проверяй читаемость и выравнивание HUD на целевых разрешениях. Интерфейс должен оставаться понятным при смене размера окна.
