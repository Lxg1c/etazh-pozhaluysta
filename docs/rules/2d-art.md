# 2D-графика

- Храни редактируемые исходники пиксельных спрайтов и анимаций в Aseprite. Слои и кадры нужны для последующих правок.
- Проверяй импорт и масштаб пиксельных ассетов в Unity на целевых разрешениях. Это позволяет вовремя заметить размытие, дрожание и обрезку кадров.
- Оставляй в кадре ту часть объекта, по которой игрок распознаёт его назначение. Игрок должен увидеть вход и знак рядом с ним с игрового ракурса.

Визуальные решения «Этаж, пожалуйста» описаны в [GDD](../../design/gdd/game-design.md). Подробности о 2D-освещении есть в [заметках по Unity](../../unity-architecture.md#данные-и-фиксированный-шаг).

Проверенные приёмы работы со спрайтами, дверями и светильниками собраны в [unity-2d-art-workflow](../../.agents/skills/unity-2d-art-workflow/SKILL.md).
