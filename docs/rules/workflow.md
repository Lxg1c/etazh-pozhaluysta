# Процесс, пайплайн и ревью

- Соблюдай порядок согласования реализации из [AGENTS.md](../../AGENTS.md). Пользователь должен видеть объём работ до начала изменений.
- Используй [game-production-pipeline](../../.agents/skills/game-production-pipeline/SKILL.md) для плана, майлстоунов, готовности этапа и выбора следующего шага. Сверяй границы работ и критерии готовности с [производственным планом](../../design/production-plan.md).
- Сверяй C#-изменения с [чек-листом ревью](../../csharp-code-review.md). Это помогает проверить стиль, границы ответственности и критерии готовности.
- Обновляй актуальный GDD при изменении правил игры. Так дизайн, код и проверки опираются на одну договорённость.
- Для десктопного релиза сверяйся с [порядком сборки, проверки ZIP и публикации](../../.agents/skills/game-production-pipeline/references/unity-desktop-builds.md).
